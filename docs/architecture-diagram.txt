DATA FLOW PATHS
===============

► DISPLAY PATH (Server → Client):
  Teensy USB Serial → /dev/ttyACM0 → bridge.py → WS:8765 → Tailscale VPN
  → M8WebSocketClient → M8Protocol (SLIP decode) → M8DisplayBuffer → M8Screen

► AUDIO PATH (Server → Client):
  Teensy USB Audio → ALSA hw:N,0 → arecord → opusenc → audio_stream.py → WS:8766
  → Tailscale VPN → M8AudioClient → OpusDecoder → M8AudioPlayer (AudioTrack)

► INPUT PATH (Client → Server):
  Touch/Gamepad/Tilt → M8Controls → KeyMapper → M8Commands → M8WebSocketClient
  → WS:8765 → Tailscale VPN → bridge.py → /dev/ttyACM0 → Teensy USB Serial

► LATENCY BUDGET:
  Display: ~15-30ms (serial read + WS relay + SLIP decode + render)
  Audio:   ~40-80ms (ALSA capture + Opus encode + WS relay + decode + playback)
  Input:   ~10-20ms (key event + WS send + serial write)
