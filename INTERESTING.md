# INTERESTING — M8 Improvement Ideas

Drawn from Dirtywave M8 firmware changelog, MOD WIGGLER threads, Elektronauts, KVR, and DOA forum discussions. Reddit (r/M8Tracker) was unreachable directly, so community wishes were sourced from the forums above plus the official changelog for context on what's already shipped vs. still missing.

## 20 Possible Improvements

1. **Hardware volume control** — Users on Elektronauts/MOD WIGGLER repeatedly ask for a physical volume knob/encoder; software-only output is risky with IEMs.
2. **4-pole (24 dB/oct) filter option** — Recurring wish; current filters are musical but some users want a steeper ladder-style response.
3. **Per-track compressor with sidechain** — Directly quoted wish from MOD WIGGLER ("the only thing I miss a little").
4. **Better beat slicing / jungle workflow** — Current slicing is "quite simple"; users want auto-slice-to-grid, transient detection, and per-slice pitch/rev.
5. **Longer pattern length than 16 steps without chaining phrases** — "To do a 4-bar pattern we need 4 phrases… slightly tedious." An optional 32/64-step phrase mode would help.
6. **Improved battery life / low-power mode** — 4-hour runtime is a pain point; a dim-screen/eco mode could extend it.
7. **Song-level arrangement view** — A zoomed-out timeline showing all chains/phrases at once for easier structural editing.
8. **Pattern/phrase naming or color tagging** — Ease navigation in large projects where everything is just hex IDs.
9. **Undo history with multiple steps** — Current undo is limited; a deeper history stack (even 8–16 steps) would reduce anxiety.
10. **Stereo sample recording from line-in with monitoring** — Changelog shows repeated line-in fixes; a polished dedicated recording mode is still wanted.
11. **Per-track send effects bus (reverb/delay) with proper routing matrix** — Currently FX are per-instrument; a global send bus would free voices.
12. **Granular/wavetable instrument type** — M8 has FM and macrosynth; a true granular engine is a common wish for texture work.
13. **Copy/paste across projects** — Moving a phrase/chain/instrument between projects is currently awkward.
14. **MIDI CC learn / mapping to macros** — Cleaner external controller integration beyond hard-coded CC numbers.
15. **Polyphonic tracks (stacked voices on one track)** — Would simplify chord writing without burning 4 tracks.
16. **Scale/key quantize per track** — Auto-constrain notes and randomization to a chosen scale.
17. **Improved sample browser with waveform preview and tagging** — Finding samples on large SD cards is slow; tags/favorites would help.
18. **Euclidean rhythm generator as an FX command or groove mode** — Frequently requested for techno/jungle workflows.
19. **Stem export over USB / multi-track bounce to SD** — Multichannel USB audio exists, but a one-button offline stem render is still missing.
20. **Live performance mode** — Mute/solo groups, scene launching, and latch-recordable parameter locks for gigging without risking the song data.
