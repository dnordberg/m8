# Structure

## Top-Level Layout

```
/m8/
├── app/                       # Android Kotlin app (main product)
├── m8-synth/                  # Rust DSP crate → libm8_synth.so
├── server/                    # Python WebSocket servers (bridge + emulator)
├── generate_font.py           # Helper script to generate M8 bitmap font
├── build.gradle.kts           # Top-level Gradle build
├── settings.gradle.kts
├── gradlew / gradlew.bat
└── INTERESTING.md             # Feature ideas (non-planning)
```

## Android App

```
app/
├── build.gradle.kts           # Compose, OkHttp, Coroutines, JNI loading
├── src/main/
│   ├── AndroidManifest.xml
│   ├── assets/
│   │   └── m8_font.png        # Generated by generate_font.py
│   ├── jniLibs/               # Prebuilt libm8_synth.so drops
│   └── java/com/m8droid/
│       ├── MainActivity.kt                # Activity entry point
│       ├── M8ViewModel.kt                 # ~547 lines, orchestration
│       ├── emulator/
│       │   ├── M8Emulator.kt              # ~1200 lines, 8-screen rendering
│       │   ├── M8Song.kt                  # Song data model
│       │   ├── M8Instrument.kt            # Voice parameters
│       │   ├── M8FxEngine.kt              # FX command dispatch
│       │   ├── M8Synth.kt                 # Kotlin DSP fallback
│       │   ├── M8sParser.kt               # .m8s song loader
│       │   └── M8iParser.kt               # .m8i instrument loader
│       ├── audio/
│       │   ├── M8AudioPlayer.kt           # AudioTrack output sink
│       │   ├── NativeSynth.kt             # JNI bridge to Rust
│       │   ├── M8AudioClient.kt           # Remote audio WebSocket
│       │   └── OpusDecoder.kt             # Opus decompression
│       ├── protocol/
│       │   ├── M8Protocol.kt              # SLIP frame decoder
│       │   ├── M8DisplayBuffer.kt         # 320×240 raster buffer
│       │   └── M8Commands.kt              # Protocol constants
│       ├── network/
│       │   └── M8WebSocketClient.kt       # Remote-mode client
│       ├── ui/                            # Compose screens + components
│       ├── input/                         # Keyboard + gamepad mapping
│       ├── data/                          # Settings persistence
│       ├── browse/                        # File browser / downloader
│       └── tutorial/                      # Interactive tutorial
└── src/test/                              # EMPTY — no tests
```

## Rust Synth Crate

```
m8-synth/
├── Cargo.toml                 # crate-type = ["cdylib"]
└── src/
    └── lib.rs                 # ~615 lines — 8 voices, PolyBLEP, SVF, ADSR, delay, reverb, JNI exports
```

Build output: `libm8_synth.so` dropped into `app/src/main/jniLibs/<abi>/`.

## Python Servers

```
server/
├── m8_emulator.py             # ~1579 lines — standalone headless M8 emulator
├── bridge.py                  # Serial→WebSocket bridge (real M8 hardware)
└── audio_stream.py            # Opus streamer, spawns opus-tools subprocess
```

## Key Locations (where to add things)

| I want to... | Go to... |
|--------------|----------|
| Add a UI screen | `app/.../ui/` + register in navigation |
| Add an FX command | `app/.../emulator/M8FxEngine.kt` |
| Add a synth feature | `m8-synth/src/lib.rs` and mirror in `M8Synth.kt` |
| Handle a new protocol frame | `app/.../protocol/M8Protocol.kt` + `M8Commands.kt` |
| Add an input mapping | `app/.../input/` |
| Change song/instrument file parsing | `M8sParser.kt` / `M8iParser.kt` |
| Touch server-side emulator logic | `server/m8_emulator.py` |
| Change remote audio path | `server/audio_stream.py` + `app/.../audio/M8AudioClient.kt` |
| Persist user settings | `app/.../data/` |

## Naming Conventions

- **Kotlin files/classes**: `PascalCase` (`M8ViewModel.kt`)
- **Kotlin packages**: `com.m8droid.<area>` (lowercase)
- **Python modules**: `snake_case.py`
- **Rust**: `snake_case` files, items, and modules
- **M8-specific prefixes**: Kotlin files in the emulator/protocol layers are prefixed `M8` (`M8Emulator`, `M8Protocol`, `M8DisplayBuffer`) to distinguish from framework types.
